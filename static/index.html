YouTube Video Opportunity Analyzer

raw input → data collection → mathematical calculation → AI audit (GLM‑5.3) → final decision → published result → feedback → calibration

Honesty rules: this tool produces an evidence-based opportunity score. It is not a probability of going viral, it does not reproduce YouTube's private recommendation algorithm, and monetization figures are scenarios, not promises.
